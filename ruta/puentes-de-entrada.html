Puentes de entrada

Son cápsulas opcionales para consultar cuando una idea de los cuadernos te produzca dudas. Diagnóstico inicial reúne algunas preguntas para orientarte. Los bloques de esta página son ejemplos completos e independientes de Python, salvo cuando una celda indica explícitamente que continúa otra. No necesitas aprender toda la API antes de empezar los Laboratorios guiados.

1 · Funciones, clases y contratos

Una función recibe valores y devuelve un resultado. Especificar qué acepta y qué rechaza permite distinguir una entrada inválida de un cálculo incorrecto.

Una clase agrupa estado y operaciones. self es la instancia concreta sobre la que se ejecuta el método; dos instancias pueden tener estados distintos.

Para explorar: agrega un método reiniciar que ponga valor en cero; demuestra que reiniciar a no cambia b. Esto prepara la lectura de modelos con atributos, no exige diseñar una jerarquía de clases.

2 · Entorno, rutas, JSON y tracebacks

El intérprete que ejecuta una celda determina qué paquetes puede importar. Un notebook es un documento con celdas; su kernel es el proceso que conserva variables. Ejecutar una celda antigua fuera de orden puede esconder una dependencia: reinicia el kernel y ejecuta todo para comprobar el recorrido.

Una ruta relativa empieza en la carpeta actual del kernel. Path("datos") / "tabla.csv" une componentes sin asumir la barra de un sistema operativo. Si aparece FileNotFoundError, imprime la carpeta actual y comprueba nombre, extensión y extracción del ZIP. Instalar paquetes no repara una ruta incorrecta.

JSON guarda números, textos, booleanos, listas y diccionarios; no serializa automáticamente cualquier objeto de Python. Este ejemplo escribe solo en una carpeta temporal y la elimina al terminar:

Un traceback se lee desde la última línea: tipo de excepción y mensaje; luego busca la última línea de tu código en la pila. Imprime entradas relevantes, no todo el dataset. NameError suele ser una variable no definida o una celda omitida; ModuleNotFoundError, un paquete ausente en ese intérprete; ValueError puede indicar valor o forma incompatible. El mensaje concreto decide qué revisar; no todos se arreglan instalando o reiniciando.

Para explorar: explica una ruta inexistente y un import ausente como dos problemas distintos; escribe y relee un resultado JSON. Prueba un notebook que corre desde kernel limpio sin depender de una variable creada manualmente.

3 · Vectores, formas y multiplicación

Un vector guarda varias coordenadas; una matriz puede apilar una por fila. X @ W es producto matricial: las dimensiones interiores deben coincidir. X * X multiplica componente a componente y responde otra operación.

Para explorar: calcula manualmente la primera entrada de X @ W como suma de productos. Predice antes de ejecutar por qué (3,) + (3,1) da (3,3): NumPy amplía dimensiones compatibles, lo que puede ser válido para la librería y equivocado para tu intención.

4 · Estadística y unidades independientes

Media = suma/n. Varianza poblacional = promedio de las diferencias al cuadrado respecto de la media; desviación = raíz de la varianza, en las unidades originales. En la estandarización de los laboratorios usamos ddof=0. Estimar varianza muestral con corrección ddof=1 es otro contrato, no un detalle intercambiable.

Ocho mediciones de un sensor no son ocho sensores distintos. La unidad independiente depende de cómo se usarán las predicciones: para sensores nuevos, divide por sensor; para el futuro de sensores conocidos, respeta el tiempo. Un promedio sobre pocas unidades puede variar bastante entre muestras. Media y desviación de folds describen variación del procedimiento, no una garantía del score futuro ni automáticamente un intervalo de confianza.

Para explorar: resuelve [2,2,5] (media 3, varianza poblacional 2) y diseña el split para diez diálogos con veinte mensajes cada uno si llegarán diálogos nuevos. La respuesta divide diálogos enteros, no mensajes al azar.

5 · Probabilidad condicional y métricas

P(A | B) pregunta por A dentro de los casos B; no suele ser igual a P(B | A). Si entre diez alertas emitidas ocho eran verdaderas, precision = 8/10. Si existían veinte casos positivos y detectaste ocho, recall = 8/20. La primera restringe a predicciones positivas; la segunda a positivos reales.

La regla de Bayes reorganiza el conteo: P(A | B) = P(B | A) P(A) / P(B) cuando P(B) > 0. No añade evidencia: obliga a considerar cuánto aparece A en la población. Por eso el desbalance importa al interpretar alertas.

Para explorar: explica por qué accuracy 0.86 puede ocultar que se perdió el 60% de los positivos. En 04 - Métricas y el laboratorio 03 observarás cómo ranking y umbral influyen de forma distinta sobre estas decisiones.

6 · Derivada como sensibilidad local

La derivada mide cómo cambia una salida ante un cambio pequeño de entrada. Para L(w)=(w-3)^2, la derivada es 2(w-3). Cerca de w=1 vale −4: aumentar ligeramente w reduce L. El descenso de gradiente usa w_nuevo = w - tasa * derivada; una tasa demasiado grande puede saltarse la zona donde esa aproximación local sirve.

Con varias entradas, el gradiente reúne una derivada por coordenada. Si una salida depende de una variable intermedia, la regla de la cadena multiplica sensibilidades a lo largo de esa dependencia. Para u=2w, L=u², tenemos dL/du=2u, du/dw=2 y dL/dw=4u=8w. Esto prepara 10 - Gradientes y backpropagation; memorizar símbolos sin comprobar un cambio pequeño no es el objetivo.

Para explorar: verifica numéricamente el ejemplo encadenado cerca de w=1 y explica el signo del paso que reduce la pérdida. No necesitas derivar una red completa antes de comenzar con modelos clásicos.
